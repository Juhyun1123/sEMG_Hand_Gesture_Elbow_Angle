# sEMG 손동작·팔꿈치 각도 분류 모델 성능 비교

## 1. 코드 설명

### 데이터 및 전처리

5채널 sEMG CSV 64개를 사용했다. 샘플링 주파수는 1 kHz이며, `mark`를 시행 시작으로 해석해 1,920개 시행을 구성했다. 파일명의 손동작 코드 4종(`extor`, `fist`, `open`, `pro`)과 팔꿈치 각도 2종(30°, 60°)을 결합해 8클래스로 분류한다. `extor`는 원자료 표기를 유지했다.

시행별로 60 Hz 노치와 20–450 Hz 4차 Butterworth 필터를 적용했다. 마커 후 1.5–3.5초를 분석하는 강의 실습 가정에 따라 2초 구간을 추출하고, 200 ms 창을 100 ms 간격으로 나눠 시행당 19개 창을 만들었다. 각 창에서 RMS·MAV·WL·ZC·SSC를 5채널에 계산해 25차원 특징을 구성했다. StandardScaler는 학습 데이터에만 fit했다.

### 모델 및 학습·테스트

강의의 SVM(RBF)·Random Forest(100개 트리)·XGBoost(400개 트리)에 KNN(k=5)·LDA를 추가했다. 모든 모델에 같은 특징과 분할을 적용했다.

시행 단위로 층화 80:20 분할했다(`random_state=42`). 학습은 1,536시행·29,184창, 테스트는 384시행·7,296창이다. 같은 시행의 중첩 창이 학습·테스트에 섞이지 않도록 했다. 2–4절의 성능과 Confusion Matrix는 창 단위 평가이며 Precision·Recall·F1은 macro 평균이다. 같은 피험자의 다른 시행은 양쪽에 포함될 수 있다.

### 실행 방법

Python 3.12 환경에서 프로젝트 루트의 다음 명령을 실행한다. 데이터는 `data/`에 두고 결과는 `outputs/`에 저장한다.

```bash
python -m pip install -r requirements-lock.txt
python main.py
```

## 2. 모델 성능 비교

| Model | Accuracy | Precision | Recall | F1-score |
| --- | --- | --- | --- | --- |
| SVM | 0.4818 | 0.4936 | 0.4818 | 0.4832 |
| RF | 0.6367 | 0.6384 | 0.6367 | 0.6371 |
| XGB | 0.6246 | 0.6260 | 0.6246 | 0.6248 |
| KNN | 0.4988 | 0.5061 | 0.4988 | 0.4983 |
| LDA | 0.2967 | 0.3221 | 0.2967 | 0.2999 |

### 성능 분석

RF가 Accuracy 63.67%, macro F1 0.6371로 가장 높았고, LDA가 macro F1 0.2999로 가장 낮았다. RF는 여러 트리로 특징의 비선형 관계와 조합을 표현하므로 이번 25차원 특징 분포에 적합했을 가능성이 있다. 선형 경계를 사용하는 LDA는 상대적으로 낮은 성능을 보였다.

## 3. Confusion Matrix 분석

행은 정답, 열은 예측이다. 가장 잘 분류된 클래스와 많이 오분류된 클래스는 클래스별 Recall을 기준으로 판단했다. 원인 설명은 오분류 패턴에 근거한 가설이다.

### SVM

![SVM Confusion Matrix](outputs/confusion_SVM.png)

- 가장 잘 분류된 클래스: 30_extor (Recall 58.33%).
- 가장 많이 오분류된 클래스: 30_pro (Recall 39.36%).
- 주요 오분류 유형: `60_extor` → `30_extor` 213개; `30_pro` → `30_extor` 155개.
- 오분류가 발생한 이유에 대한 분석: 각도별 특징 분포가 겹치는 구간을 기본 RBF 설정으로 충분히 구분하지 못했을 가능성이 있다.

### RF

![RF Confusion Matrix](outputs/confusion_RF.png)

- 가장 잘 분류된 클래스: 30_fist (Recall 68.86%).
- 가장 많이 오분류된 클래스: 30_pro, 60_pro (Recall 60.31%).
- 주요 오분류 유형: `30_pro` → `60_pro` 99개; `60_pro` → `30_pro` 98개.
- 오분류가 발생한 이유에 대한 분석: 같은 동작에서 각도 변화에 따른 차이가 작아, 여러 트리로도 일부 특징 구간을 구분하기 어려웠을 가능성이 있다.

### XGB

![XGB Confusion Matrix](outputs/confusion_XGB.png)

- 가장 잘 분류된 클래스: 30_extor (Recall 67.54%).
- 가장 많이 오분류된 클래스: 30_pro (Recall 57.02%).
- 주요 오분류 유형: `30_fist` → `60_fist` 122개; `30_pro` → `60_pro` 110개.
- 오분류가 발생한 이유에 대한 분석: 같은 동작의 각도별 특징이 유사해 부스팅 모델에서도 오류가 남았을 가능성이 있다.

### KNN

![KNN Confusion Matrix](outputs/confusion_KNN.png)

- 가장 잘 분류된 클래스: 30_fist (Recall 60.20%).
- 가장 많이 오분류된 클래스: 60_pro (Recall 39.47%).
- 주요 오분류 유형: `60_extor` → `30_extor` 190개; `60_pro` → `30_pro` 158개.
- 오분류가 발생한 이유에 대한 분석: 표준화한 특징 공간에서 다른 클래스의 표본이 가까운 이웃에 포함됐을 가능성이 있다.

### LDA

![LDA Confusion Matrix](outputs/confusion_LDA.png)

- 가장 잘 분류된 클래스: 60_pro (Recall 38.05%).
- 가장 많이 오분류된 클래스: 30_pro (Recall 22.48%).
- 주요 오분류 유형: `30_pro` → `60_pro` 249개; `60_extor` → `30_extor` 238개.
- 오분류가 발생한 이유에 대한 분석: 클래스별 분포를 선형 경계와 동일 공분산 가정으로 구분하는 데 한계가 있었을 가능성이 있다.

## 4. 최종 결과

- 가장 성능이 좋은 모델: **RF** (macro F1 0.6371).
- 가장 성능이 낮은 모델: **LDA** (macro F1 0.2999).
- 주요 오분류 클래스: RF 기준 `30_pro` → `60_pro` 99개; `60_pro` → `30_pro` 98개.
- 전체적인 실험 결과 및 느낀 점: 동일한 데이터와 특징을 사용해도 모델에 따라 성능과 오류 패턴이 달랐다. 전체 정확도와 함께 클래스별 Recall과 Confusion Matrix를 확인해야 취약한 동작·각도 조합을 찾을 수 있었다. 또한 중첩 창의 분할 단위를 지키고 평가 단위를 명확히 하는 것이 성능 수치만큼 중요하다는 점을 확인했다.

## 5. 추가 분석

### 시행별 다수결 평가 실행

```bash
python main.py --trial-vote
```

기본 창별 평가에 더해, 테스트 시행 384개 각각의 19개 창 예측을 묶어 가장 많이 나온 라벨 하나를 최종 예측으로 선택한다. 최빈 라벨이 동률이면 LabelEncoder 순서와 같은 사전순 첫 라벨을 선택한다. 여기서 다수결은 과반 득표가 필요 없는 최빈값 투표이다. 학습 모델·데이터 분할·전처리는 기본 실험과 같다.

### 정확도 비교

| Model | 창별 정확도 | 시행별 다수결 정확도 | 증가폭 (%p) | 시행별 F1-score |
| --- | --- | --- | --- | --- |
| SVM | 48.18% | 76.04% | +27.86 | 0.7665 |
| RF | 63.67% | 94.27% | +30.61 | 0.9426 |
| XGB | 62.46% | 94.79% | +32.33 | 0.9477 |
| KNN | 49.88% | 88.02% | +38.14 | 0.8821 |
| LDA | 29.67% | 40.89% | +11.21 | 0.4128 |

`python main.py --trial-vote`의 추가 평가 결과이며, Precision·Recall·F1은 기존과 같은 macro 평균을 사용했다. 네 지표와 정확도 증가폭은 [결과 CSV](outputs/week3_trial_vote_metrics.csv)에, 시행별 예측은 `outputs/trial_predictions_모델명.csv`에 저장된다.

시행별 다수결에서는 XGB가 정확도 94.79%로 가장 높았다. 창별 평가에서 가장 높았던 RF와 순위가 달라져, 평가 단위와 예측 집계 방식에 따라 모델 순위도 달라질 수 있음을 확인했다.

### 정확도가 높아진 이유에 대한 유추

- 200 ms 창 하나에는 순간적인 잡음이나 근활성 변화가 반영될 수 있다. 한 시행의 여러 창을 합치면서 일부 창의 오분류가 최종 판정에 미치는 영향이 줄었을 가능성이 있다.
- 틀린 창의 예측이 여러 클래스에 분산되면 정답 라벨의 득표가 과반이 아니어도 최빈값이 될 수 있다. 실제 RF에서 정답으로 분류한 362시행 중 62시행은 정답 득표가 19개 중 9개 이하였다. 이 때문에 창별 정확도보다 시행별 정확도가 크게 높아질 수 있다.
- LDA도 정확도가 높아졌지만 다른 모델보다 낮았다. 같은 잘못된 라벨로 일관되게 예측하는 오류는 투표만으로 해소하기 어려웠을 가능성이 있다.

이 결과는 새로운 학습으로 창별 분류 능력이 높아진 것이 아니라, 동일한 예측을 창 7,296개 대신 시행 384개 단위로 평가한 결과이다. 중첩 창 19개는 독립 표본이 아니며, 시행별 판정에는 분석 구간 2초의 창 예측이 필요하다. 이번에는 모든 모델의 정확도가 높아졌지만 다른 데이터에서도 향상을 보장하지는 않는다.
